# 二创工场 · Recut Studio

面向带货短视频的**轻量二创工作台**。纯前端，打开 `index.html` 就能用，不需要安装、不需要后端、不需要账号；所有数据留在浏览器本地。

默认配置锁定 **9:16 竖屏 · 1080×1920 · 10–30 秒 · 抖音/快手/视频号带货**。

---

## 四个工作台

| 模块 | 做什么 | 输入 | 输出 |
| --- | --- | --- | --- |
| 01 文案拆解与改写 | 拆出钩子/痛点/卖点/信任/引导五段结构，按秒重写 | 原文案、品类、人群、卖点、风格、时长 | 结构表 + 指标 + 分段口播稿 + 标签 + 合规预检 |
| 02 AI 提示词反推 | 反推可复用的七段式生成提示词 | 商品、卖点、视觉风格、时长、比例、模型 | 视频提示词（基础参数/人物/服装/场景/分镜/BGM/标签）+ 文生图提示词 + 负面提示词 |
| 03 分镜脚本生成 | 输出可直接开拍的执行方案 | 商品、卖点、片型风格、时长、钩子、语气 | 画面参数、人物设定、场景光影、逐秒分镜表、字幕、转场滤镜、BGM、标签 |
| 04 素材与任务 | 沉淀稿件、按批次跟进度 | 手动录入或一键存稿 | 素材卡（含压缩封面）+ 任务看板（待剪辑/已出稿/已发布）+ JSON 备份 |

05 设置与备份：接入任意 OpenAI 协议的模型接口，或导出/清空本地数据。

## 快速开始

```bash
# 方式一：双击即用
直接用浏览器打开 index.html

# 方式二：本地起服务（推荐，剪贴板权限更完整）
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

1. 把本仓库推到 GitHub（默认分支 `main`）。
2. 仓库 **Settings → Pages → Build and deployment**：Source 选 `Deploy from a branch`，Branch 选 `main` / `root`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

仓库根目录的 `index.html` 是页面骨架，样式与逻辑在 `assets/`（`app.css`、`app.js`、`prompt.js`、`story.js`、`assets.js`）。`.nojekyll` 保证静态资源按原样发布，无需任何构建步骤。

## 接入 AI（可选）

不接 AI 也能出完整的结构与骨架，接上模型后改写、台词质量取决于模型本身。

在「设置与备份」里填写：

- 接口地址：任意 OpenAI 兼容端点，例如 `https://ark.cn-beijing.volces.com/api/v3`
- API Key：只写进本机 `localStorage`，不会上传到任何服务器
- 模型名称：例如 `doubao-seed-1-6`、`gpt-4o-mini` 等

点「测试连接」验证；成功后点「启用 AI 增强」。浏览器直连要求服务端允许 CORS，若被拦截会提示网络错误，此时继续用本地引擎即可。

## 数据

- 素材、任务、设置存于浏览器 `localStorage`（前缀 `recut.`），换浏览器或清缓存会丢失。
- 「导出备份」产出 JSON；「导入」按 `id` 去重合并，不会覆盖已有数据。
- 上传的封面会压缩到 480px、JPEG 质量 0.72 再存储，避免撑爆本地容量。

## 设计取舍与限制

- **不抓取平台数据**：视频链接只作备注。纯前端无法解析抖音/快手页面，这是浏览器同源策略决定的，不是没做。
- **本地引擎是规则 + 模板**：文案结构判定靠关键词与位置启发式，改写输出的是可执行的骨架，不是成品文案；需要成稿质量请接 AI。
- **分镜是执行建议**：时间码、景别、运镜按固定片型预设生成，实际拍摄需按场地与模特调整。
- **合规预检**只覆盖常见绝对化用语，不替代平台的广告审核。

## 技术说明

纯静态 HTML/CSS/JS，按模块拆分为若干脚本，原生 JavaScript，无框架、无构建、无外部依赖（仅字体走 CDN，加载失败自动回退系统字体）。移动端自适应，支持 `prefers-reduced-motion`。
